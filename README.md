# Design and Analysis of Algorithms

This repository contains my **Design and Analysis of Algorithms (DAA)** practical programs, implementations, and problem-solving exercises using **C++**.

The repository follows the practical syllabus and covers important algorithmic techniques such as Recursion Removal, Heaps, Divide and Conquer, Greedy Algorithms, Dynamic Programming, and Backtracking.
